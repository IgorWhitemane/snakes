# Симуляция змейки в PyBullet

Этот проект содержит набор скриптов и утилит для обучения и запуска модели управления змейкой в физическом движке **PyBullet**. Змейка может управляться как вручную, так и с помощью алгоритма обучения с подкреплением `PPO` из библиотеки `stable_baselines3`.

## Структура репозитория

- `main.py` — обучение модели `PPO` в окружении `SnakeEnv` и сохранение веса в файл `snake_ppo.zip`;
- `run.py` — запуск обученной модели в режиме визуализации и вывод действий с наградами;
- `run_human.py` — режим ручного управления с клавиатуры;
- `agent/` — создание змейки и логика взаимодействия с едой;
- `models/` — дополнительные элементы симуляции (например, стены игрового поля);
- `utils/` — реализация среды Gymnasium и вспомогательные функции.

## Запуск

1. Установите зависимости: `stable-baselines3`, `gymnasium`, `pybullet`, `numpy`.
2. Для обучения выполните:
   ```bash
   python main.py
   ```
   Модель будет сохранена в `snake_ppo.zip`.
3. Для просмотра работы обученной модели запустите:
   ```bash
   python run.py
   ```
4. Чтобы управлять змейкой вручную, используйте:
   ```bash
   python run_human.py
   ```

## Логи

Все логи обучения сохраняются в папку `logs/` и могут быть просмотрены через TensorBoard.
